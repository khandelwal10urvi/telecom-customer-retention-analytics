# Telecom Customer Retention & Churn Analytics

## Overview

Analyzed 7,043 telecom customer records to identify churn patterns and high-risk customer segments using Python and Excel/Google Sheets.

## Tools

Python · Pandas · NumPy · Matplotlib · Seaborn · Excel/Google Sheets

## Analysis

- Data cleaning and validation
- Feature engineering using `ChurnFlag`, `TenureBand`, and `MonthlyChargeBand`
- Churn analysis by contract, tenure, internet service, payment method, and monthly charges
- KPI and pivot-based dashboard development

## Key Insights

- Overall churn rate: **26.54%**
- Month-to-month churn: **42.71%**
- 0–12 month tenure churn: **47.44%**
- Electronic check churn: **45.29%**
- Fiber optic churn: **41.89%**

> Findings represent observed associations in the dataset, not causal relationships.
